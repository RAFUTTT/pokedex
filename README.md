# Tutorial: Creación de Cuenta en la Nube

## 1. Introducción
Este documento detalla el proceso de registro y configuración inicial en la plataforma de nube seleccionada para el despliegue de la aplicación **Pokédex** (Pueblo Paleta Inc.).

## 2. Pasos para la Creación de la Cuenta
1. Se ingresó a la plataforma de despliegue elegida (ej. Deno Deploy o Vercel).
2. Se hizo clic en el botón de registro vinculando las credenciales oficiales de **GitHub**.
3. Se autorizó el acceso seguro a los repositorios para permitir la integración continua y el despliegue automático del código fuente.
